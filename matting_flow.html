Trimap

Lecture 10.1 matting.py:189–194

The binary mask already gives a dense FG/BG labeling, so the trimap is built geometrically: erode and dilate the mask with a disc of radius RHO = 7. The eroded core is certain foreground, everything outside the dilation is certain background, and the ring between them is the undecided band Bρ(Δ) around the contour.

αT(x) = 1  on erode(mask, discρ)
αT(x) = 0  outside dilate(mask, discρ)
αT(x) = φ  in the band (width ≈ 2ρ)

early exit empty mask (bbox_of_mask returns None, :177–179) → α = 0 everywhere, matted frame = new background.

Color model — KDE

Lectures 10.1 / 10.4 matting.py:206–211

FG and BG color densities are estimated only from pixels adjacent to the band (within SAMPLE_RADIUS = 25), where color statistics are local and reliable. The 3-D Parzen KDE over Lab uses the binned low-rank trick: quantize into a 64³ histogram, then apply the separable Gaussian kernel as three 1-D convolutions — O(samples + bins) instead of the quadratic direct sum.

f(c|F), f(c|B) = gaussian_filter(hist64³(Lab ≫ 2), σ = 2)
P(F|c) = f(c|F) / ( f(c|F) + f(c|B) )  (Bayes, uniform priors)
kde_3d posterior_fg cv2.cvtColor → Lab np.bincount scipy gaussian_filter
fallback no FG or no BG samples near the band (:210) → band pixels keep α = 0 and the confident-only composite stands.

Opacity map — geodesic distances

Lecture 10.2 matting.py:214–230

An 8-neighbor graph is built over the band plus thin confident rims on both sides. Each edge costs the posterior jump |P(u) − P(v)| — the discrete line integral of the lecture’s weight field W = ∇P(F|c) — plus a small spatial regularizer. Multi-source Dijkstra from each rim gives DF and DB, blended into α.

cost(u→v) = |P(u) − P(v)| + ε·step
D_F, D_B = Dijkstra(band graph, sources = rims)
w_F = DF−r · P(F|c)   w_B = DB−r · P(B|c)   (r = 2)
α(x) = wF / ( wF + wB )
band_graph geodesic_dist csr_matrix scipy dijkstra (min_only)
fallback a rim side is empty (:228–229) → skip the geodesics and use the posterior directly: α = P(F|c) on the band.

Matting — pure foreground color

Lecture 10.3 matting.py:232–233

Blending the observed band color directly would drag the old background into the new one. Instead, for each band pixel a KD-tree fetches the N_CAND = 7 nearest confident FG and BG pixels; the pair whose α-blend best reconstructs the observed color yields the pure foreground color used in the final composite.

(xF*, xB*) = argmin ‖ α·c(x_F) + (1−α)·c(x_B) − c(x) ‖²
J(x) = α(x) · c(x_F*) + (1 − α(x)) · B_new(x)
pure_composite scipy cKDTree ×2 7 × 7 candidate pairs / pixel
fallback no confident candidates on one side (:152–153) → naive blend α·c + (1−α)·B_new.
