2 How two people avoid blocking each other

The pipeline is a straight dependency chain, so naïvely B waits for A forever. The trick is contract‑first development: agree the exact file formats up front, then everyone develops against a stand‑in file of that format.

Why this split

The chain is Stabilize → Subtract → Matte → Track. Cutting it in the middle gives two self‑contained halves joined by one seam:

  • A
  • B

Effort is balanced: each half contains one of the two hardest stages (Stabilization ≈ Matting) plus one lighter stage (Subtraction ≈ Tracking). Themes also line up with the reading list, so each person reads a coherent set of chapters.

7 Developer A — Motion & Foreground

Owns the front half of the chain. Starts immediately on INPUT.avi — no dependency on B.

1Stabilization → stabilize.avi

The camera is hand‑held and shaky; the scene is static. Warp every frame onto the coordinate system of frame 0. Read ch01 (affine/homography, homogeneous coords), ch02 (Lucas‑Kanade, Harris), ch03 (RANSAC) first.

Definition of done: stabilize.avi is 1920×1080, 205 frames, background visibly locked (play it; the doorframe shouldn't jitter). Hand this file + the format to B.

2Background Subtraction → binary.avi + extracted.avi

After stabilization each pixel shows its true background most of the time and the person only briefly. Model each pixel's background and flag values that are “too far” from it. Read ch08 (why Gaussians, per‑pixel, ω/σ, online updates, failure modes).

Optional easier path (FAQ #10): OpenCV's createBackgroundSubtractorKNN/MOG2 is allowed, but you must explain how it works in the report — and heavy reliance on contrib‑style shortcuts risks the 70‑pt cap. Prefer your own per‑pixel model.

8 Developer B — Matte & Track

Owns the back half. Starts immediately against the fixture stabilize + binary videos in Temp/fixtures/; swaps in A's real files at integration.

3Matting → matted.avi + alpha.avi

Inputs (FAQ #7): background.jpg, stabilize.avi, binary.avi. Follow ch10's flow Trimap → Opacity map → Matte. Crop to the person's bounding box each frame to stay fast.

Definition of done: on the fixtures, the person sits cleanly on background.jpg with soft, non‑jagged edges and no colour halo. alpha.avi is a clean silhouette that fades at the boundary.

4Tracking → OUTPUT.avi + tracking.json

Select the person automatically in the matted video and track it with a Kalman filter (ch04). No manual init allowed.

Grading note: tracking is scored by deviation from a secret ground truth. Prefer a tight box on the person's silhouette and a filter tuned to stay stable rather than chase every noisy detection.
