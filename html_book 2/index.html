The tracking recursion, proved

Markov + conditional independence ⇒ p(x1:t|z1:t) ∝ p(zt|xt) p(xt|xt−1) p(x1:t−1|z1:t−1). Seven lines, each assumption used exactly once, plus a Bayes filter you can step. Ch.4 · 12 pts

Text as a dynamic texture

Swap the single offset for a bounded max-heap. The three details that break it — duplicates, diversity, where random search is centred — with the algorithm running live on four repeated motifs. Ch.11 · 13 pts
B6
